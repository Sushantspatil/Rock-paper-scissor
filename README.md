# Rock-paper-scissor

✊✋✌️ Rock Paper Scissors Game
A simple and interactive Rock-Paper-Scissors game built using HTML, CSS, and JavaScript. Play against the computer, see real-time results, and enjoy smooth animations and responsive design. Great for practicing DOM manipulation and game logic in JavaScript!

🔧 Tech Stack:
        HTML5    
        CSS3
        Vanilla JavaScript

🎮 Features:
    Real-time result display
    Score tracking
    Random computer moves
    Responsive & clean UI
